# 第23章项目任务：智能购物车

## 业务背景

为一个电商平台设计一个购物车类，购物车需要支持常见的容器操作：添加商品、按索引访问、遍历、获取数量，还要能打印友好的购物清单，并支持两个购物车合并。

## 技术要求

### 设计 `Product` 类（商品）

- 属性：`sku`（商品编号）、`name`、`price`、`quantity`
- `__repr__`：`Product('P001', '苹果', 5.0, 3)`
- `__str__`：`苹果 × 3 = ¥15.00`
- `__eq__`：同一 `sku` 视为相同商品
- `__hash__`：基于 `sku`

### 设计 `ShoppingCart` 类（购物车）

实现以下魔术方法：

| 魔术方法 | 行为 |
|----------|------|
| `__len__` | 返回购物车中商品种类数 |
| `__getitem__` | 按索引或 sku 获取商品 |
| `__setitem__` | 更新商品数量 |
| `__contains__` | `product in cart` 判断商品是否在购物车 |
| `__iter__` | 支持 `for item in cart` |
| `__add__` | 合并两个购物车（`cart1 + cart2`） |
| `__str__` | 打印格式化购物清单 |
| `__repr__` | 返回 `ShoppingCart(n件商品, 总价¥xxx.xx)` |

### 其他方法

- `add_item(product)`：添加商品，若已存在则增加数量
- `remove_item(sku)`：删除商品
- `total_price()`：计算总价
- `apply_discount(percent)`：折扣，返回新购物车（不修改原购物车）

## 验收标准

- [ ] 所有魔术方法均可正常调用
- [ ] `len(cart)`、`cart[0]`、`product in cart` 均正常工作
- [ ] `cart1 + cart2` 返回新购物车，原购物车不变
- [ ] `print(cart)` 输出格式化的清单（含总价）
- [ ] `apply_discount` 返回新对象（不修改原对象）

## 示例输出

```
  香蕉      × 2   ¥ 3.50  小计：¥  7.00

─────────────────────────────────────
  共 3 种商品          总计：¥ 34.80

打九折后：¥31.32

ShoppingCart(3件商品, 总价¥34.80)

合并后购物车共 5 种商品
```
