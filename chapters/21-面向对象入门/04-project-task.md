# 第21章项目任务：员工信息管理系统

## 业务背景

某小型公司需要一个简单的员工信息管理工具，用于记录员工的基本信息、职位和薪资，并能统计公司整体的人员和薪资情况。

## 技术要求

### 1. 设计 `Employee` 类

**实例属性（在 `__init__` 中初始化）：**
- `employee_id`：员工编号（字符串，如 `"EMP001"`）
- `name`：姓名
- `department`：部门
- `salary`：月薪（浮点数）
- `hire_year`：入职年份（整数）

**类属性：**
- `company_name`：公司名称（字符串，自行定义）
- `employee_count`：员工总数（每次实例化自动加1）
- `total_salary`：所有员工薪资总和（每次实例化时累加）

**实例方法：**
- `get_annual_salary()`：返回年薪（月薪 × 12）
- `get_seniority(current_year=2024)`：返回工龄（当前年份 - 入职年份）
- `raise_salary(percent)`：按百分比涨薪，更新实例属性和类属性中的总薪资
- `info()`：打印员工信息摘要

### 2. 公司统计功能

编写独立函数 `company_stats(employees)`，接受员工列表，打印：
- 公司名称和员工总数
- 平均薪资
- 薪资最高/最低员工
- 各部门人数统计

## 验收标准

- [ ] `Employee` 类有完整的 `__init__` 方法
- [ ] 类属性 `employee_count` 能正确追踪实例数量
- [ ] `raise_salary` 能同时更新实例属性和类属性 `total_salary`
- [ ] `company_stats` 函数能正确计算统计数据
- [ ] 代码运行无报错，输出格式整洁
- [ ] 创建至少5名员工进行测试，涵盖不同部门
