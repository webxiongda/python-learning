# 第01章：环境搭建与Python初印象 — 项目任务

## 项目名称：个人开发环境搭建 + "Hello Me" 程序

---

## 业务背景

每一位程序员职业生涯的第一步，都是搭建属于自己的开发环境。这个任务模拟真实工作中"入职第一天配置开发机"的场景——你需要从零开始，搭建一套规范的 Python 开发环境，并交付一个能够运行的小程序作为验收成果。

---

## 技术要求

### 环境搭建部分

1. **安装 Python 3.10 及以上版本**，验证可通过 `python3 --version` 查看版本号
2. **安装并配置 pyenv**（可选但推荐），能够切换 Python 版本
3. **在项目目录下创建虚拟环境** `.venv`，并激活
4. **通过 pip 安装以下依赖**：
   - `rich`（用于美化终端输出）
5. **生成 `requirements.txt`** 文件

### 程序开发部分

创建文件 `hello_me.py`，实现以下功能：

1. 程序启动时，打印欢迎横幅（使用 `rich` 库的 Panel 或自定义 ASCII 艺术均可）
2. 依次询问用户：姓名、年龄、最想学习的 Python 应用方向（如 Web/数据/自动化）
3. 根据输入生成一段个性化的"学习宣言"并打印
4. 打印当前 Python 版本和操作系统信息
5. 所有输出要有清晰的格式，不能是一坨纯文本

---

## 验收标准

| 验收项 | 具体要求 | 通过条件 |
|--------|----------|----------|
| 环境配置 | 虚拟环境创建成功 | `.venv/` 目录存在，激活后提示符有 `(.venv)` |
| 依赖管理 | requirements.txt 存在且内容正确 | 文件包含 `rich==x.x.x` |
| 程序运行 | `python3 hello_me.py` 无报错 | 程序正常运行到结束 |
| 交互功能 | 能接受用户输入 | 三个问题均可正常输入并回显 |
| 输出格式 | 输出有格式区分 | 至少使用了分隔线、缩进或颜色中的一种 |
| 代码质量 | 有基本注释 | 每个功能块有至少一行说明注释 |
