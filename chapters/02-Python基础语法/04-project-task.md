# 第02章：Python 基础语法 — 项目任务

## 项目名称：简易单位换算器

---

## 业务背景

日常生活和工作中经常需要进行单位换算：体重（千克/磅）、温度（摄氏度/华氏度）、距离（公里/英里）等。本任务要求你用本章所学的变量、数据类型和运算符，构建一个简单的单位换算计算器。

这个场景非常真实——许多在线工具、手机 App 中的换算功能，其核心逻辑正是这几行数学运算和格式化输出。

---

## 技术要求

创建文件 `converter.py`，实现以下功能：

### 1. 温度换算
- 接收用户输入的摄氏度
- 转换为华氏度：`F = C × 9/5 + 32`
- 转换为开尔文：`K = C + 273.15`

### 2. 距离换算
- 接收用户输入的公里数
- 转换为英里：`miles = km × 0.621371`
- 转换为海里：`nautical = km × 0.539957`

### 3. 重量换算
- 接收用户输入的千克数
- 转换为磅：`lb = kg × 2.20462`
- 转换为盎司：`oz = kg × 35.274`

### 4. 输出要求
- 每项换算结果保留 2 位小数
- 输出格式整齐，使用对齐和分隔线
- 程序结束前打印一条"感谢使用"的提示

---

## 验收标准

| 验收项 | 具体要求 |
|--------|----------|
| 输入处理 | 使用 `float(input(...))` 正确接收数字输入 |
| 计算正确 | 各换算公式结果误差 < 0.01 |
| 输出格式 | 使用 f-string，保留 2 位小数 |
| 变量命名 | 使用有意义的英文变量名（snake_case） |
| 代码注释 | 每个换算区域有说明注释 |
