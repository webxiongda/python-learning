## 1. *args 与 **kwargs

### 1.1 位置可变参数 *args

`*args` 允许函数接收任意数量的位置参数，在函数内部以**元组**形式存在。

```
调用：func(1, 2, 3)
         ↓
函数内：args = (1, 2, 3)  ← 元组
```

```python
def 求和(*args):
    total = 0
    for n in args:
        total += n
    return total

print(求和(1, 2, 3))        # 6
print(求和(10, 20, 30, 40)) # 100
```

### 1.2 关键字可变参数 **kwargs

`**kwargs` 允许函数接收任意数量的关键字参数，在函数内部以**字典**形式存在。

```
调用：func(name="张三", age=25)
         ↓
函数内：kwargs = {"name": "张三", "age": 25}  ← 字典
```

```python
def 打印信息(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

打印信息(name="张三", age=25, city="北京")
```

### 1.3 参数顺序规则

```
┌─────────────────────────────────────────────┐
│         Python 函数参数顺序                   │
│                                             │
│  普通参数 → *args → 默认参数 → **kwargs      │
│                                             │
│  def func(a, b, *args, key=val, **kwargs)   │
└─────────────────────────────────────────────┘
```

```python
def 综合示例(必填, *args, 默认值=0, **kwargs):
    print(f"必填: {必填}")
    print(f"args: {args}")
    print(f"默认值: {默认值}")
    print(f"kwargs: {kwargs}")

综合示例("hello", 1, 2, 3, 默认值=99, x=10, y=20)
```

### 1.4 解包传参

`*` 和 `**` 不仅用于定义，也可在调用时用于解包：

```python
def add(a, b, c):
    return a + b + c

nums = [1, 2, 3]
print(add(*nums))  # 等价于 add(1, 2, 3)

info = {"a": 10, "b": 20, "c": 30}
print(add(**info)) # 等价于 add(a=10, b=20, c=30)
```

## 2. 默认参数陷阱

### 2.1 可变对象作为默认值

这是 Python 中最常见的陷阱之一！

```python
# ❌ 错误写法
def 添加元素(item, lst=[]):
    lst.append(item)
    return lst

print(添加元素(1))  # [1]
print(添加元素(2))  # [1, 2]  ← 预期是 [2]！！
print(添加元素(3))  # [1, 2, 3]  ← 越来越长！
```

**原因分析：**

```
┌─────────────────────────────────────────┐
│  函数定义时，默认值 [] 只创建一次        │
│                                         │
│  def func(lst=[])                       │
│                  ↑                      │
│              同一个列表对象              │
│              每次调用共享此对象          │
└─────────────────────────────────────────┘
```

```python
# ✅ 正确写法：使用 None 作为哨兵值
def 添加元素(item, lst=None):
    if lst is None:
        lst = []   # 每次调用创建新列表
    lst.append(item)
    return lst
```

## 3. 闭包（Closure）

### 3.1 什么是闭包

闭包是一个**记住了外部作用域变量**的函数。

```
┌──────────────────────────────────────────┐
│              闭包的结构                   │
│                                          │
│   外部函数                               │
│   ┌──────────────────────────────────┐   │
│   │  外部变量 x = 10                 │   │
│   │                                  │   │
│   │   内部函数（闭包）               │   │
│   │   ┌──────────────────────────┐   │   │
│   │   │  可以访问并记住 x         │   │   │
│   │   └──────────────────────────┘   │   │
│   └──────────────────────────────────┘   │
└──────────────────────────────────────────┘
```

```python
def 计数器工厂():
    count = 0           # 外部变量

    def 递增():
        nonlocal count  # 声明使用外部变量
        count += 1
        return count

    return 递增         # 返回函数本身，不是调用结果

counter = 计数器工厂()
print(counter())  # 1
print(counter())  # 2
print(counter())  # 3
```

### 3.2 nonlocal 关键字

`nonlocal` 用于在内层函数中修改外层函数的变量（不是全局变量）：

```python
def 外层():
    x = 10

    def 内层():
        nonlocal x   # 声明 x 来自外层作用域
        x += 5
        print(x)

    内层()  # 15
    print(x)  # 15（外层的 x 也被修改了）

外层()
```

**与 global 的对比：**

```
global   → 访问/修改模块级全局变量
nonlocal → 访问/修改最近一层外部函数的变量
```

### 3.3 闭包的实用场景

```python
def 乘法器(倍数):
    def 乘法(数字):
        return 数字 * 倍数
    return 乘法

double = 乘法器(2)
triple = 乘法器(3)

print(double(5))  # 10
print(triple(5))  # 15
```

## 4. 高阶函数：map 与 filter

高阶函数是**接收函数作为参数**或**返回函数**的函数。

### 4.1 map() 函数

`map(函数, 可迭代对象)` 对每个元素应用函数，返回迭代器。

```
输入: [1, 2, 3, 4, 5]
      ↓  ↓  ↓  ↓  ↓
    平方 平方 ...
      ↓  ↓  ↓  ↓  ↓
输出: [1, 4, 9, 16, 25]
```

```python
numbers = [1, 2, 3, 4, 5]

# 使用 map
squares = list(map(lambda x: x**2, numbers))
print(squares)  # [1, 4, 9, 16, 25]

# 等价的列表推导式
squares2 = [x**2 for x in numbers]
```

### 4.2 filter() 函数

`filter(函数, 可迭代对象)` 过滤出使函数返回 True 的元素。

```
输入: [1, 2, 3, 4, 5, 6]
      ↓  ↓  ↓  ↓  ↓  ↓
    偶数? 偶数? ...
      ✗  ✓  ✗  ✓  ✗  ✓
输出: [2, 4, 6]
```

```python
numbers = [1, 2, 3, 4, 5, 6]

evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens)  # [2, 4, 6]
```
