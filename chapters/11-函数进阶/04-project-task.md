# 第11章项目任务：通用数据处理管道

## 业务背景

你在一家电商公司担任后端开发，需要构建一个灵活的**数据处理管道**。业务方经常需要对用户订单数据进行不同组合的过滤、转换和聚合操作，每次都写重复代码效率太低。你决定利用函数进阶特性，构建一个可复用的管道系统。

## 技术要求

### 核心功能

1. **管道构建器**：使用闭包实现 `make_pipeline(*funcs)` 函数，它接收多个处理函数，返回一个新函数，该函数将数据依次通过所有处理步骤。

2. **过滤工厂**：使用闭包实现 `make_filter(**conditions)` 函数，接收任意关键字条件，返回一个过滤函数（用于 `filter()`）。

3. **字段提取器**：使用 `map` 实现 `extract_fields(*fields)` 函数，从字典列表中提取指定字段。

4. **统计聚合**：实现 `summarize(data, *fields)` 函数，对数值字段计算 总计/平均/最大/最小。

### 测试数据

```python
订单数据 = [
    {"订单号": "001", "用户": "张三", "金额": 299.0, "状态": "已完成", "城市": "北京"},
    {"订单号": "002", "用户": "李四", "金额": 1599.0, "状态": "已完成", "城市": "上海"},
    {"订单号": "003", "用户": "王五", "金额": 89.0,  "状态": "已取消", "城市": "北京"},
    {"订单号": "004", "用户": "赵六", "金额": 2399.0, "状态": "已完成", "城市": "广州"},
    {"订单号": "005", "用户": "钱七", "金额": 459.0, "状态": "待支付", "城市": "上海"},
]
```

### 使用示例

```python
# 期望能这样使用：
管道 = make_pipeline(
    lambda data: filter(make_filter(状态="已完成"), data),
    lambda data: list(data),
    lambda data: sorted(data, key=lambda x: x["金额"], reverse=True),
)

结果 = 管道(订单数据)
# 应得到：已完成订单，按金额降序排列
```

## 验收标准

- [ ] `make_pipeline` 正确链式执行所有处理步骤
- [ ] `make_filter` 支持多个条件同时过滤（AND 逻辑）
- [ ] `extract_fields` 使用 `map` 实现字段提取
- [ ] `summarize` 正确计算数值统计
- [ ] 以上函数全部使用闭包、*args、**kwargs 实现，不使用类
- [ ] 编写至少3个测试用例验证功能正确性

## 进阶挑战（可选）

给管道添加**错误处理**：如果某个步骤抛出异常，记录错误并跳过该数据项，而不是让整个管道崩溃。提示：在 `make_pipeline` 内部使用 `try/except`。
