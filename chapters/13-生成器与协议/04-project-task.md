# 第13章项目任务：流式CSV处理器

## 业务背景

公司数据团队需要处理一个 50 万行的用户行为CSV文件（约 200MB）。传统方式一次性读入内存会导致 OOM（内存溢出）。你需要用生成器实现**流式处理管道**，让数据逐行流过处理链，内存占用保持在 10MB 以内。

## 技术要求

### 核心组件（全部用生成器实现）

1. **行读取器**：`读取CSV行(文件路径)` — 生成器，逐行 yield 字典（字段名来自首行）。

2. **数据清洗器**：`清洗数据(rows)` — 生成器，过滤空行、去除字段首尾空格、跳过解析失败的行。

3. **字段转换器**：`转换字段(rows, **转换规则)` — 生成器，根据转换规则（如 `age=int, salary=float`）对字段进行类型转换。

4. **统计聚合器**：`统计聚合(rows, 分组字段, 数值字段)` — 消费生成器，输出分组统计结果。

### 管道组合方式

```python
# 期望这样使用：
pipeline = 统计聚合(
    转换字段(
        清洗数据(
            读取CSV行("用户行为.csv")
        ),
        age=int, salary=float
    ),
    分组字段="department",
    数值字段="salary"
)
```

## 验收标准

- [ ] 使用生成器实现（含 yield），不使用列表存储中间结果
- [ ] 清洗器正确过滤空行（`空行` = 所有字段为空）
- [ ] 转换失败的行（如 age="abc"）被跳过并打印警告
- [ ] 统计聚合输出各部门的人数、平均薪资、最高薪资
- [ ] 使用 `yield from` 至少一次
- [ ] 添加一个 `计数装饰器` 统计每个生成器处理了多少行（使用闭包）

## 进阶挑战（可选）

实现 `批量写入器(rows, 批大小=1000)` 生成器，将处理好的数据按批次写入，每批完成后 yield 一个进度报告字典，格式为 `{"已处理": n, "当前批次": m}`。
