学习本章时不要只记 API 名称，要持续回答三个问题：

1. 这个能力解决什么问题？
2. 它应该放在项目的哪一层？

## 在项目中的使用场景

- FastAPI 接口：把输入解析、业务规则、数据访问和错误响应拆开。
- AI 应用后端：把模型调用、提示词、缓存、日志、任务状态和历史记录拆成稳定边界。
- 数据处理任务：读取外部数据后，先清洗和校验，再聚合、转换和输出。
- 测试与复盘：给核心函数写边界用例，把踩坑写回 `mistakes.md`。

## 常见错误和排查信号

- 只写 demo 不写包结构
- 没有版本和 README
- 测试只覆盖 happy path

排查时优先看：

- 输入是否符合预期类型和结构。
- 函数是否有明确返回值，而不是只打印。
- 异常是否带有足够上下文。
- 是否能用一个最小测试复现问题。
