# 第03章：控制流程 — 项目任务

## 项目名称：数字统计与分析工具

---

## 业务背景

数据分析的第一步往往是对原始数字进行基础统计：找最大值/最小值、计算平均值、统计频率分布等。本任务要求你综合运用 for 循环、while 循环、条件判断和 break/continue，实现一个从命令行收集数字并进行统计分析的小工具。

这类功能在实际工作中非常常见——数据处理脚本、批量计算工具、测试结果统计等都会用到这些基础控制结构。

---

## 技术要求

创建文件 `number_analyzer.py`，实现以下功能：

### 功能 1：数字收集
- 使用 `while` 循环持续接收用户输入的数字
- 输入 `done` 或 `q` 时停止收集
- 输入非数字内容时提示错误并继续收集（不终止程序）
- 至少收集 1 个有效数字才能进行分析

### 功能 2：基础统计
对收集到的数字进行以下统计（不使用 `sum()`、`max()`、`min()` 等内置函数，手动用循环实现）：
- 总数量
- 总和
- 平均值
- 最大值
- 最小值

### 功能 3：分布分析
使用循环和条件判断统计：
- 正数、负数、零的数量
- 奇数、偶数的数量（整数才统计）

### 功能 4：格式化输出
将统计结果以整齐的报告形式打印。

---

## 验收标准

| 验收项 | 具体要求 |
|--------|----------|
| 输入容错 | 非数字输入不崩溃，给出提示并继续 |
| 终止条件 | 输入 `done` 或 `q` 正常退出收集 |
| 统计正确 | 手动循环计算的结果与内置函数结果一致 |
| 分布统计 | 正负零数量之和等于总数量 |
| 输出格式 | 报告有标题、分隔线、对齐的标签和值 |
