# 第12章项目任务：日志分析器

## 业务背景

你的团队服务器每天产生大量日志文件，运维需要快速从日志中提取关键信息：错误统计、IP 访问频率、时间段分析等。由于日志文件可能非常大（数GB），需要使用生成器表达式避免内存爆炸。

## 技术要求

### 输入数据格式

```python
# 模拟日志条目
日志条目 = [
    "2024-01-15 10:23:45 ERROR 192.168.1.1 数据库连接失败",
    "2024-01-15 10:24:01 INFO  10.0.0.1 用户登录成功",
    "2024-01-15 10:24:55 WARN  192.168.1.2 响应时间过长",
    "2024-01-15 10:25:12 ERROR 192.168.1.1 文件不存在",
    "2024-01-15 10:25:33 INFO  10.0.0.2 查询执行",
    "2024-01-15 10:26:01 ERROR 10.0.0.1 权限拒绝",
    "2024-01-15 10:27:45 INFO  192.168.1.1 用户登出",
]
```

### 核心功能（全部用推导式/生成器实现）

1. **日志解析**：用列表推导式将每行日志解析为字典 `{时间, 级别, IP, 消息}`。

2. **错误过滤**：用生成器表达式筛选出所有 ERROR 级别的日志（考虑大文件场景）。

3. **IP 统计**：用字典推导式统计每个 IP 的出现次数（提示：先用列表推导式提取所有 IP）。

4. **错误 IP 集合**：用集合推导式找出所有触发过 ERROR 的 IP 地址。

5. **分级汇总**：用字典推导式生成 `{级别: 数量}` 的统计字典。

### 验收标准

- [ ] 日志解析结果为字典列表，字段完整
- [ ] 错误过滤使用生成器表达式（不是列表推导式）
- [ ] IP 统计字典正确（每个 IP 的出现次数）
- [ ] 错误 IP 集合使用集合推导式实现
- [ ] 分级汇总结果：`{'ERROR': 3, 'INFO': 3, 'WARN': 1}`
- [ ] 所有核心功能的代码不超过 10 行（不含注释和数据定义）

## 进阶挑战（可选）

- 支持 `for 条目 in 日志迭代器(日志条目, 级别="ERROR")` 的用法
