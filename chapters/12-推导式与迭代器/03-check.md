## 题目1：推导式语法

以下代码的输出结果是什么？

```python
result = [x * y for x in range(1, 4) for y in range(1, 4) if x != y]
print(result)
```

### 参考答案

```
[2, 3, 2, 6, 3, 6]
```

解析：x 和 y 各取 1, 2, 3，但排除 x==y 的情况：
- x=1: y=2 → 2, y=3 → 3
- x=2: y=1 → 2, y=3 → 6
- x=3: y=1 → 3, y=2 → 6

## 题目2：字典推导式

给定两个列表 `keys = ['a', 'b', 'c']` 和 `values = [1, 2, 3]`，用一行字典推导式将它们合并为字典 `{'a': 1, 'b': 2, 'c': 3}`。

### 参考答案

```python
keys = ['a', 'b', 'c']
values = [1, 2, 3]

# 方法1：zip + 字典推导式
result = {k: v for k, v in zip(keys, values)}
print(result)  # {'a': 1, 'b': 2, 'c': 3}

# 方法2：直接用 dict()
result2 = dict(zip(keys, values))
print(result2)  # {'a': 1, 'b': 2, 'c': 3}
```

`zip()` 函数将两个可迭代对象"拉链式"配对，字典推导式再把每对 (k, v) 构成字典条目。

## 题目3：生成器表达式

以下两段代码有什么关键区别？各自适合什么场景？

```python
# 代码A
result_a = [x**2 for x in range(1000)]
total_a = sum(result_a)

# 代码B
result_b = sum(x**2 for x in range(1000))
```

### 参考答案

**主要区别：**

| 特征 | 代码A（列表推导式） | 代码B（生成器表达式） |
|------|---------------------|----------------------|
| 内存 | 创建包含1000个元素的完整列表 | 只保存生成器状态，极少内存 |
| 可重用 | result_a 可多次使用 | 生成器耗尽后不可重用 |
| 速度 | 略慢（需分配内存） | 略快（惰性计算） |

**适用场景：**
- 代码A（列表）：需要多次访问结果、需要索引、需要 len()
- 代码B（生成器）：只需遍历一次、数据量大、节省内存

## 题目4：迭代器协议

以下代码会输出什么？为什么？

```python
my_iter = iter([1, 2, 3])
print(next(my_iter))
print(next(my_iter))

for x in my_iter:
    print(x)

print(list(my_iter))
```

### 参考答案

```
1
2
3
[]
```

解析：
1. `next(my_iter)` 取出 1
2. `next(my_iter)` 取出 2
3. `for x in my_iter` 接着从第3个元素开始，打印 3（然后迭代器耗尽）
4. `list(my_iter)` 迭代器已经耗尽，转换为空列表

关键：迭代器只能前进，不能重置。调用 `iter()` 会创建新的迭代器，已有的迭代器不受影响。

## 题目5：综合应用

使用推导式和生成器，处理以下任务：给定员工数据，用最简洁的方式（不超过3行）找出"年龄 > 30 且薪资 > 10000"的员工姓名列表，以及计算所有符合条件员工的平均薪资。

```python
员工 = [
    {"name": "张三", "age": 28, "salary": 12000},
    {"name": "李四", "age": 35, "salary": 15000},
    {"name": "王五", "age": 32, "salary": 9000},
    {"name": "赵六", "age": 45, "salary": 25000},
]
```

### 参考答案

```python
员工 = [
    {"name": "张三", "age": 28, "salary": 12000},
    {"name": "李四", "age": 35, "salary": 15000},
    {"name": "王五", "age": 32, "salary": 9000},
    {"name": "赵六", "age": 45, "salary": 25000},
]

# 筛选符合条件的员工
符合条件 = [e for e in 员工 if e["age"] > 30 and e["salary"] > 10000]

# 获取姓名列表
姓名列表 = [e["name"] for e in 符合条件]
print("符合条件:", 姓名列表)  # ['李四', '赵六']

# 计算平均薪资（使用生成器表达式）
平均薪资 = sum(e["salary"] for e in 符合条件) / len(符合条件)
print(f"平均薪资: {平均薪资:.0f}")  # 20000

# 一行版本（更紧凑）
结果 = [(e["name"], e["salary"]) for e in 员工 if e["age"] > 30 and e["salary"] > 10000]
print("一行版:", 结果)  # [('李四', 15000), ('赵六', 25000)]
```

注意：王五（age=32, salary=9000）被排除，因为薪资不满足条件。
