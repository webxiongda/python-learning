# Python 全栈学习路线

> 60章系统学习路线 · 全栈通用方向 · 理论→Demo→验收→项目

## 当前使用方式

本仓库按“学习文档 + 项目交付”组织：

- `learning-goal.md`：学习目标、默认节奏和三层路线。
- `progress.md`：章节推进状态。
- `review-plan.md`：间隔复习计划。
- `mistakes.md`：错题本和踩坑复盘。
- `chapters/`：每章理论、Demo、验收题、项目任务。
- `chapters/*/review.md`：每章复习记录、费曼输出和错题回收。
- `projects/`：6 个里程碑项目的真实代码工作区。
- `tools/check_learning_repo.py`：检查章节结构、模板化内容和项目目录。

建议先完成第一层主线，不要从第 01 章平均推进到第 60 章：

```text
第一层：01-12、15、29、39、41、44、46、50、51
第二层：13-28、31-34、42-49、52-56
第三层：35-38、57-60
```

运行质量检查：

```bash
python tools/check_learning_repo.py
```

如果本机没有 `python` 命令，使用：

```bash
python3 tools/check_learning_repo.py
make all
```

内容维护标准见 `docs/CONTENT-QUALITY.md`。

## 优先级说明

| 标记 | 含义 |
|------|------|

| L2 项目常用 | 中高级开发常用，重点学习 |
