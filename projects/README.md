## 通用交付标准

- 每个项目必须有 `README.md`，写清目标、运行命令、测试命令和踩坑记录。
- 核心逻辑必须能被测试调用，不只写在命令行或接口函数里。
- 正常路径和异常路径都要有测试。
- 运行产生的数据、缓存、虚拟环境不提交。
- 完成项目后，同步更新根目录 `progress.md`、`review-plan.md` 和 `mistakes.md`。

## 推荐节奏

1. 先实现最小可运行版本。
2. 再补核心测试。
3. 最后整理 README 和复盘记录。
4. 不在项目初期追求复杂架构，优先保证职责清晰、能运行、能测试。
